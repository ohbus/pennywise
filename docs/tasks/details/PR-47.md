# PR-47 — PostgreSQL populated-settlement reconciliation evidence

- Phase: production_hardening
- Owner role: coordinator
- Dependencies: PR-17, PR-46
- Owned paths: opt-in Expense Core PostgreSQL settlement reconciliation test and task evidence

## Objective

Produce executable PostgreSQL evidence for the settlement ledger invariants with
both recorded and reversed settlements present.

## Acceptance criteria

- The test creates a recorded settlement and a reversed settlement through the
  real JPA store.
- Recorded settlements have exactly two postings; reversed settlements have
  exactly four postings.
- Settlement postings net to zero and signs match the settlement direction.
- The test is opt-in and documents the required PostgreSQL environment.

## Validation

- `$env:PENNYWISE_POSTGRES_TESTS='true'; $env:SPRING_DATASOURCE_URL='jdbc:postgresql://localhost:5432/pennywise_expense_core'; $env:SPRING_DATASOURCE_USERNAME='pennywise'; $env:SPRING_DATASOURCE_PASSWORD='pennywise-local-only'; ./gradlew.bat :app:expense-core:test --tests '*PostgresSettlementReconciliationTest' --rerun-tasks --no-daemon`
- `git diff --check`

## Current increment

The opt-in `PostgresSettlementReconciliationTest` creates recorded and reversed
settlements through `JpaSettlementStore`, flushes the transaction, and asserts
the PostgreSQL posting counts, zero-sum totals, and directional signs. It
passed against the local Compose PostgreSQL database with the declared
environment settings.

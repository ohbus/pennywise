# PR-49 — Bound GraphQL transport request sizes

- Phase: production_hardening
- Owner role: coordinator
- Dependencies: PR-20, PR-37, PR-43
- Owned paths: BFF application configuration and transport tests, and this task detail

## Objective

Prevent oversized GraphQL HTTP bodies and headers from consuming unbounded BFF
memory before GraphQL depth and complexity instrumentation runs.

## Acceptance criteria

- BFF request headers have an explicit finite maximum.
- BFF codec request buffering has an explicit finite maximum.
- Limits are configurable through deployment properties with safe defaults.
- Existing GraphQL transport tests remain passing.

## Validation

- `./gradlew.bat :app:bff:test --rerun-tasks --no-daemon`
- `git diff --check`

## Current increment

Configured BFF codec buffering to 256 KB and request headers to 16 KB by
default, with deployment overrides through `PENNYWISE_BFF_MAX_BODY_SIZE` and
`PENNYWISE_BFF_MAX_HEADER_SIZE`. The full BFF test suite passed.

# DB-04 — Implement separate writer and reader connection pools

Add validated Spring configuration for one writer and named reader pools,
bounded Hikari settings, per-route pool budgets, startup validation, and an
explicit local `reader-is-writer` diagnostic mode. Flyway and Hibernate
validation must use the writer only.

Acceptance includes configuration binding tests, missing/invalid endpoint
tests, pool-budget tests, datasource identity tests, migration-writer tests,
and documentation of PostgreSQL `max_connections` accounting.

## Concrete code targets

- Update the three service `src/main/resources/application.yml` files with `pennywise.db.writer`, `pennywise.db.readers`, pool limits, timeouts, and diagnostic mode.
- Add environment keys to `infra/local/.env.example`, deployment Compose files, and `infra/versions.env.example` without credentials.
- Wire writer-only Flyway/Hibernate validation in `DbAutoConfiguration` and prove it with application context tests.
- Add `DbConfigurationTest`/context tests under `libs/db/src/test` and each service’s existing persistence test package.
- Verify `app/bff/build.gradle.kts` and architecture checks reject any `libs:db` dependency.
